| 조건                                        | 처리 방식                                |
  |-------------------------------------------|--------------------------------------|
| placeholder + 전체 명령어중 승인필요가 존재하는 경우       | 승인요청 → 승인완료 → 웹 터미널에서 사용자가 직접 명령어 실행 |
| placeholder + 전체 명령어중 승인필요가 존재하지 않는 경우    | CommandParameterDialog → 순차 실행       |
| No placeholder + 전체 명령어중 승인필요가 존재하는 경우    | 승인요청 → 승인완료 → 순차 실행                  |
| No placeholder + 전체 명령어중 승인필요가 존재하지 않는 경우 | 바로 순차 실행                             |
